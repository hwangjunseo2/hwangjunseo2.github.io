For the Open Source Software course, I built my personal homepage using Jekyll and GitHub Pages.

I forked the Academic Pages template, customized the configuration in `_config.yml`, and rewrote the main page in `about.md`. After each change, I committed and pushed it to GitHub, and GitHub Actions rebuilt the site automatically.

This was a good chance to practice the Git workflow and see how a static site is generated from Markdown files.
